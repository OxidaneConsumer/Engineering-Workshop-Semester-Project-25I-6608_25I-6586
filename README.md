Our Project:
Manual parking gate systems require human supervision and are prone to safety issues, such as the gate closing while a vehicle is still present. 
There is a need for a system that ensures secure entry, reduces human labour, and prevents accidents. 
Our project uses RFID-based authentication to allow only authorized vehicles to enter. 
An ultrasonic sensor detects the presence of a vehicle and ensures the gate operates only when needed, while also preventing it from closing if a vehicle is still under the gate. 
A servo motor controls the gate movement, and an IR remote provides manual override for emergency situations.
LED indicators give clear feedback for successful or failed access(green for success and red for failure).
